# PASTA LA VISTA — パスタ・サバイバーズ

イタリア人の目の前でパスタを折って追い払う、3D版 Vampire Survivors 風ゲーム。Unity 6000.6.1f1 / URP。

## 試す

- 製品版：`output/SurvivorsRelease/PastaSurvivors.exe`（同じフォルダーのデータと一緒に起動）
- 開発版：`output/Survivors/PastaSurvivors.exe`（F1〜F6 のデバッグキー付き）
- Unityでは `Assets/Scenes/Survivors.unity` を開いて Play。シーンには起動用オブジェクトが1つあるだけで、ステージ・敵・UIはすべて実行時に生成される。
- 再ビルド：Unityメニューの **Pasta Survivors → Build Windows Release / Build Windows Playtest (Development)**。

## 遊び方

移動するだけで、持っているパスタ武器が自動で発動する。倒したイタリア人は「Mamma mia!」と叫んで逃げ出し、パスタの欠片（経験値）を落とす。

1. **レベルアップ**：欠片を集めると3〜4択から武器かパッシブを選ぶ。武器・パッシブとも最大6枠。
2. **主武器の切り替え**：持っている武器のうち1つが「主武器」。威力1.4倍・クールダウン25%短縮に加え、武器ごとの特性が付く。状況に応じて切り替える。
3. **進化**：武器をLv8にして対応パッシブを持った状態で宝箱を開けると進化する。宝箱はノンナ（エリート）とボスが落とす。
4. **ステージ**：10分生き延びるとボスが登場。倒すとクリアして次のステージが解放される。
   イタリア人は時間と主人公のレベルに応じて強くなる。倍率はタイマーの下に表示される（例：敵 HP×2.1 攻撃×1.4）。
   - HP：ステージ倍率 ×（1 + 分 × 0.075）×（1 + (Lv−1) × 0.03）。ボスはレベル項が半分。
   - 攻撃力：ステージ倍率 ×（1 + 分 × 0.04）×（1 + (Lv−1) × 0.01）。
   - ステージ1はレベル項を HP 0.02・攻撃 0.006 に緩めている。
   - 係数は `GameData.cs` の各ステージの `hpPerMinute` / `hpPerLevel` / `damagePerMinute` / `damagePerLevel` で調整できる。
5. **パワーアップ**：集めたコインでタイトルの「ノンナの食料庫」から永続強化を買える。
6. **視点**：見下ろし（標準）と一人称（FPS）を切り替えられる。一人称では主武器が照準の方向へ飛び、右下のレーダーで背後の敵を確認できる。
7. **特殊武器**：マップの光の柱（台座）に出現する。拾うと任意のタイミングで使え、使うとクールダウンに入る。1枠のみで、別の特殊武器を拾うと元の武器は台座に残る。
8. **地形**：壁・生垣・柱はスリッパなどの投擲を防ぐ遮蔽物。イタリア人は経路探索で壁を回り込み、橋や路地を通ってくる。回復の泉は量に限りがあり、時間で少しずつ戻る。市場ではワイン樽がよく出る。ローマの車道を走る車とナポリの火山弾はイタリア人も巻き込む。

### キャラクターモデルと体型

人物はすべて `Scripts/Visual/Humans.cs` でプリミティブから組み立てる。首・肩・肘・膝・手指（怒った手は指先をすぼめた「ma che vuoi」）、靴の種類（革靴・スニーカー・スリッパ・ノンナ靴）、服の細部（襟・ベルトとバックル・帯・サスペンダー・ジャケットの襟とポケットチーフ・体の曲面に沿うエプロン・ショール・背番号10）を持つ。

敵種ごとに「人格」があり、見下ろしでもシルエット・持ち物・姿勢で見分けられ、表情と歩き方も違う。

| 種類 | シルエット・持ち物 | 姿勢・動き | 表情 |
| --- | --- | --- | --- |
| シニョーレ | 鳥打帽、太鼓腹、ピンクのガゼッタ紙 | 反り返り・がに股でドスドス歩く | 怒りっぽい（への字口、寄せた眉、眉間のしわ） |
| ティフォーゾ | 頭上ではためく旗（外見ごとに三色旗・青白・赤黄） | 前傾で跳ねるように走る | 絶叫（見開いた目、大きく開いた口） |
| マンマ | カーラーかスカーフ、振り上げたスリッパ、揺れる巨大な買い物袋（ネギとパン） | 腰を左右に振る小走り | 説教（片眉だけ上げ、半目で口を斜めに開ける） |
| シェフ | 高いコック帽、遅れて揺れる巨大な腹、笏のように持つお玉 | 反り返り、がに股、あごを上げる | 高慢（目を閉じ、口をすぼめて「ふん」） |

| ノンナ | 小さく丸い背、白いお団子、振り上げた木べら | ちょこちょこ歩き、ときどき首を横に振る | 険しい（細めた目、すぼめた口と口元のしわ） |
| ベスパ乗り | スクーター | 車体を左右に振って蛇行、ときどき周りを見る | 余裕の笑み（サングラスと歯を見せた笑い） |
| ボス | — | グランデ・ノンナは麺棒を振り上げ首を振る、カピターノはがに股で大きく揺れる、ドンは反り返って肩で歩く | 激怒（歯を食いしばる）／大笑い（パイプ）／ふてぶてしい（葉巻） |

頭・腹・持ち物は体と別のパーツで、`Gait`（`Models.cs`）の値で動く：テンポ・歩幅・上下動・前傾/反り返り・腰の揺れ・肩のひねり・腕の振り・がに股・つま先の開き・首（あごの角度、うなずき、首振り、歌うような揺れ、舵取り）・腹の遅れ・乗り物の蛇行。持ち物は旗がはためく・生地が回る・袋が揺れるの3種。人格の数値は `Humans.cs` の `Enemy`、体型による補正は `Tune` で調整できる。表情は `Mood`（13種）で、`Face` が眉・まぶた・口・ほお・しわを作り分ける。

体型は9種類（`BodyType`）：標準・細身・筋肉質・ずんぐり・太め・高齢（背中が丸い）・のっぽ・小柄・巨漢。身長・肩幅・腰幅・手足の太さ・腹・姿勢が変わり、腕と脚の付け根も体型に合わせて動く。各敵種と各外見に体型を割り当てており（例：マフィオーソは巨漢、シニョーレの4種目は鳥打帽の老人）、群れのシルエットがばらける。主人公もケンジ＝筋肉質、ミナ＝小柄、タロウ＝ずんぐり。

1体あたりの頂点数は平均約4,800（従来約2,000）、描画パーツは最大8つ（体・頭・両腕・両脚・腹・持ち物）。見えない継ぎ目の蓋を省き、眼鏡や房飾りなど細部は低ポリゴンの部品で作って抑えている。

### 同じ種類の見た目バリエーション

通常敵8種類とエリートのノンナに、それぞれ **4種類（従来の見た目＋3種類）** の外見を用意。体型、服・髪・肌・瞳の色、髪型、ひげ、眼鏡、腹回り、目の間隔と鼻の大きさが異なる。ベスパ乗りは車体色・ヘルメット・ライダーの服も変わる。シェフのコック帽とお玉、ゴンドリエーレの縞シャツとオールなど、敵種の目印になる衣装と持ち物は共通。

敵種ごとに4種類をシャッフルして順に出し、一巡するたびに並びを再抽選する。外見用の乱数は戦闘用と独立しており、HP・攻撃・移動・当たり判定の数値は従来どおり。モデルと再利用プールは「敵種＋外見」で共有し、再出現時も群れに各バリエーションが混ざる。ボスと樽は従来の固有モデルを使う。外見は `Humans.cs` の `Enemy`（基本の衣装）・`VaryAppearance`（外見違い）・`Vespista` で、体型の寸法は `BodyShape.Of` で調整できる。

### 接近中のジェスチャー

ゲーム中に **G / 右スティック押し込み**、または **ポーズ → 身振り設定（再開）** で設定画面を開き、発生率スライダーを動かす。初期値は **100%**、範囲は **0〜100%**（1%刻み）。マウスのドラッグ、左右キー、パッドの十字キー／左スティックで調整し、G・Esc・B・「閉じる」で戻る。調整中もゲームは進行する。ポーズから開く場合もゲームを再開する。設定操作が移動・視点・武器操作に混ざらないよう、その間のプレイヤー入力は設定画面で受け取る。自動攻撃と敵の行動は継続する。

対象は#6と同じ **徒歩の通常敵・エリート（ノンナ）**。乗り物・ボス・樽は含まない。100%なら対象者全員、0%なら誰も新しい身振りを始めず、中間値はその割合を目安に対象者を選ぶ。個体の抽選値は出現時に一度だけ決まり、スライダーを戻すと同じ人が対象に戻る。人数比は抽選により多少前後し、同時に身振りしている割合ではない。変更は次の身振り開始判定から反映し、進行中の身振りは完了まで続く（攻撃・被弾などによる中断は優先）。設定は起動中に保持し、再起動時は100%に戻る。

空いている片手で「頭の高さまで大きく上下に振る」「横に大きく振る」「手のひらを広く差し出す」の3種類をランダムに出す。武器を持つ手は使わない。

初回の待ちは0.1〜0.75秒、動作は1.65〜2.05秒（最後のポーズを0.2秒保持）、次の待ちは0.45〜1.1秒。全員が同時に始めるのではなく、個体ごとに開始時刻・種類・使う手をずらす。`Enemy.cs` の `ResetApproachGesture` / `AnimateApproachGesture` で調整できる。

プレイヤーへ実際に近づいていて、視線が通り、接触距離より0.8m以上外側〜14m以内のときだけ出る。攻撃予告・攻撃・被弾・気絶・吹き飛び・恐怖・逃走・接近停止時は中断し、条件が戻ってから新しい動作を始める。「全員対象」は常時表示を意味しない。移動・攻撃タイマー・当たり判定は変更しない。見下ろし・一人称の両方で同じ腕の動きを使い、Vキーで視点を切り替えられる。

### ステージ

1. **ローマ**：
   - 160×144m（旧96×96mの2.5倍）のマップ。中央の広場と北の教会前は、周回して包囲をほどく開けた場所
   - 北西は9軒の家を挟む4mの路地と6mの横道。敵を通路へ絞り、家の陰で投擲を避ける。北東の遺跡は崩れた壁や柱を回り込んで射線を切る場所
   - 西の市場は屋台で曲がる通路、樽が多く敵も多い補給地点。東の庭園は4つの門がある退避場所で、有限の回復泉と少なめの増援
   - 南の8m幅の車道へ敵を誘導すると車で一掃できる。その先の遊歩道にはトレヴィの泉と特殊武器の台座があり、横に長い退避経路になる
   - 地区ごとに通常ウェーブの人数・出現間隔・敵構成を調整。人数と間隔は移動後数秒かけて変わり、既存の追手は消えない。敵の解禁時刻、定時イベント、ボスは従来のまま
   - ミニマップの色と地区名・短い案内で地形の役割を表示。地区の境界・倍率・構成は `StageBuilder.Roma` の `AddDistrict`、地形と通路も同メソッドで調整できる
2. **ヴェネツィア**：
   - 運河で4つの島に分かれ、5本の橋が要所になる
   - 橋は両岸から歩いて上れるアーチ形。頂点の歩行面は高さ3m、橋桁下面は水面から2.55mで、既存ゴンドラの船首飾りにも約1mの余裕を確保。船は静的な背景モデルのまま
   - リアルト市場、回廊の柱と回復の井戸、サン・マルコ広場、中庭のある館
3. **ナポリ**：
   - 西半分はスペイン地区風の細い路地の格子、東はコロネードのある広場
   - 回復するピッツェリア、果物市場
   - 火山弾が定期的に降る

### BGM

タイトルまたはポーズ画面の **音量設定** で、**BGM** と **SE（効果音）** を別々に0〜100%（1%刻み）で調整できる。0%でその系統だけミュート。マウスのドラッグ、上下キーでの項目選択と左右キーでの調整、パッドの十字キー／左スティックに対応する。変更は再生中の音にも即時反映し、画面を閉じると保存され、次回起動時にも引き継がれる。「初期値に戻す」はBGM **55%**・SE **40%**（従来のSE 80%から半減）。ポーズから開いた場合はゲームを止めたまま、BGMを通常の音量に戻して調整でき、Esc・B・「戻る」でポーズ画面へ戻る。

ステージ曲は `Assets/Survivors/Resources/Music/` に置いた音声ファイルを使う（現在は3ステージとも「Pursuit of the Button_no1」）。添付されたM4A内のOpus音声をOGG/Vorbisへ変換し、48kHz・ステレオ・約2分25秒の曲全体をストリーミングでループ再生する。1面（ローマ）はボス出現時に「Pasta la vista」へ切り替わり、ノンナの第2形態まで継続する。タイトルと2・3面のボス戦は実行時に合成するタランテラを使う。

- **曲の追加**：上記フォルダーに置くと、初回インポート時にストリーミング再生（Vorbis）に設定される。音量は -15 LUFS 前後でマスタリングした曲が合成BGMと揃うように合わせてある。
- **ステージごとの曲**：`GameData.cs` の各ステージの `music` に拡張子なしのファイル名を書く。空なら合成BGMに戻る。
- **ボス曲**：`bossMusic` に書くとボス出現時にその曲へ切り替わる。空なら合成のボス曲。
- **ステージ途中の切り替え**：`events` に `new StageEvent { time = 300, type = StageEventType.Music, music = "曲名" }` を足すと、その時刻から2秒かけてクロスフェードする。

## 検証

モデルの一覧：`PastaSurvivors.EditorTools.ModelGallery.Render` をバッチモード（`-nographics` なし）で実行すると、ゲームと同じ歩きアニメーションでポーズを付けた主人公と全敵種、表情、外見違い、ボス、バイクばばぁの3方向、見下ろし視点の群れを `output/Gallery/` に画像で出力する。歩きの連続フレームも `walk/`（横から）、`approach/`（正面から）、`crowd/`（ゲームの視点）に出力し、モデルごとの頂点数を `vertices.txt` に書き出す。

身振りの専用検証：Unityメニュー **Pasta Survivors → Verify Enemy Gestures**（`PastaSurvivors.EditorTools.EnemyGestureVerification.Check`）。スライダーの接続、0/25/50/75/100%、固定された対象者、次回開始への反映、攻撃・被弾の割り込み、空き手制限、歩行と戦闘データの維持を確認する。

開発版を以下で起動すると自動テストが走り、`output/Survivors/Verification/` に結果とスクリーンショットを保存する。テスト用のセーブ枠を使うので、普段のセーブデータには影響しない。

```text
PastaSurvivors.exe -survivors-smoke -screen-fullscreen 0 -screen-width 1600 -screen-height 900
```

次の項目を確認する。
- タイトル、キャラ・ステージ選択、ショップ
- 3ステージ、ボス撃破とステージ解放（グランデ・ノンナがバイクばばぁに変身して戦闘が続くことも確認）
- レベルアップ、主武器の切り替え、宝箱と全武器の進化
- 一人称（タイトルからの開始、V での切り替え）、マウスでの照準と移動
- 特殊武器5種の取得と使用
- 家を回り込む経路探索、回復の泉の枯渇、車道の車、火山弾
- ゲームオーバー、リトライ、ポーズ
- ステージ曲の再生、ボス出現時の曲切り替え

バランス確認用に、無敵なしで1ステージを遊ぶボットもある（`[ステージ0〜2] [速度倍率] [キャラ0〜2] [ショップLv]`）。成長と被ダメージの内訳を `Verification/bot-stage*.txt` に記録する。

```text
PastaSurvivors.exe -survivors-bot 0 4 0 0
```

## 旧プロトタイプ：PASTA LA VISTA — DOMINO

パスタを折って敵を飛ばし、その敵を奥の敵にぶつける、一人称の連鎖アクション。Unity 6000.6.1f1 / URP。

### 試す

- Unityで `Assets/Scenes/Main.unity` を開いてPlay。シーンの再生成は不要。
- 新しい試遊版：`output/DominoPlaytest/PastaLaVista.exe`。同じフォルダーのデータと一緒に起動する。
- 再ビルド：Unityメニューの **Pasta → Build Playtest**。
- 前の試遊版は `output/Playtest/` に残してある。

### 遊び方

1. **列の手前を狙う。** スパゲッティの金色で折ったときの射程は約4m。吹き飛ばした敵はさらに奥へ飛び、ぶつかった敵も次の弾になる。地面の矢印が発射方向。
2. **右クリックで集める。** 近くの敵を、前方の緑色の輪へ2.6秒間誘導する。5秒で再使用できる。
3. **ダッシュで角度を作る。** 横へ回り込んで敵を重ねる。ダッシュ中は短時間無敵。1.15秒で再使用できる。
4. **折って連鎖させる。** 左クリックを長押しして金色で離すと、強く遠くへ発射。重い敵も一撃になる。敵同士の衝突なら弱い発射でも重い敵を倒せる。

パスタの衝撃波が敵に当たるたびに、0.15秒かけて通常の5%の速度になり、1.5秒間スローを維持して0.25秒で元に戻る。残りの敵の数によらず発動し、重い敵を倒しきれない命中でも発動する。空振りでは発動しない。ポーズ中はスローの残り時間も停止し、死亡・クリア・リトライで通常速度に戻る。`Main` シーンの `Managers` に配置済みの `TimeManager` で速度と切り替え時間を調整できる。

3ラウンドすべて倒せばクリア。各ラウンド終了でHPが15回復する。連鎖で倒すほど追加点が増え、結果画面には最大連鎖人数と衝突で倒した人数が残る。

### 操作

| 操作 | キーボード / マウス | コントローラー |
| --- | --- | --- |
| 移動 / 視点 | WASD / マウス | 左 / 右スティック |
| 曲げて発射 | 左クリックまたはSpaceを長押し → 離す | RTまたはAを長押し → 離す |
| 挑発・集合 | 右クリック / E | LB |
| ダッシュ | 移動方向 + 左Shift（入力なしなら前方） | 左スティック + RB |
| パスタ切替 | Q、1 / 2 / 3 | X |
| ポーズ | Esc | Start |
| リトライ | R / Space / クリック | A |

- **スパゲッティ：押し出す。** 前方扇状範囲の敵を狙った方向へ発射。Tier 1/2/3 の近距離ヒット半径は 2.5/3.25/4m（連続 Perfect ボーナス前）。
- **ペンネ：狙い撃ち。** 細く長い範囲で速く発射。飛行距離は Tier 1/2/3 で 8/13/18m。
- **ラザニア：全周散らし。** 近くの敵を放射状に飛ばし、Tier 2 から重い敵のガードを破る。飛行距離は Tier 1/2/3 で 6/9/13m、再使用まで全 Tier で 2.5 秒。

敵を発射したあとの飛行距離はパスタと敵種によって変化する。敵の飛びやすさは Normal 1.0、Fast 1.4、Tough 0.4 倍。パスタのノックバックはスパゲッティ 1.0、ペンネ 0.9、ラザニア 1.3 倍。

### 発射バランス

| パスタ | Tier 1 / 2 / 3 の基本飛距離 | ノックバック倍率 | 飛行速度 | 特性 |
| --- | --- | --- | --- | --- |
| スパゲッティ | 7 / 11 / 15 m | 1.0 | 18 m/s | 基準 |
| ペンネ | 8 / 13 / 18 m | 0.9 | 24 m/s | 長距離連鎖 |
| ラザニア | 6 / 9 / 13 m | 1.3 | 18 m/s | Tier 2 から Tough の直接弾ガードを破る |

飛距離にはパスタのノックバック倍率と敵種の倍率（Normal 1.0 / Fast 1.4 / Tough 0.4）を掛ける。撃破時の吹き飛び速度とよろけ速度にも敵種の倍率を適用する。

早く離しすぎるとパスタは残る。溜めすぎると弱く折れる。敵の「!」は攻撃予告で、発射か挑発で中断でき、ダッシュでも回避できる。

### 主な実装

- `DominoShot.cs`：1発全体で共有する連鎖記録、線分による衝突判定。
- `Enemy.cs`：飛行・衝突・連鎖発射、挑発への移動、重い敵のガード。
- `PastaHand.cs`：攻撃範囲、発射方向ガイド、挑発と集合場所の表示。
- `PlayerController.cs`：方向入力に沿うダッシュ、短時間無敵、再使用時間。
- `EnemySpawner.cs`：列・重い敵・二方向からの3ラウンド構成。
- `GameManager.cs` / `Hud.cs`：勝利・敗北・再開と新ルールの日本語UI。
