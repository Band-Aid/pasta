# PASTA LA VISTA — PASTA COMBO

パスタを折って敵を飛ばし、ドロップで自動パスタを育てる一人称の連鎖アクション。材料を集めると料理コンボが完成する。Unity 6000.6.1f1 / URP。

## 試す

- Unityで `Assets/Scenes/Main.unity` を開いてPlay。シーンの再生成は不要。
- 新しい試遊版：`output/DominoPlaytest/PastaLaVista.exe`。同じフォルダーのデータと一緒に起動する。
- 再ビルド：Unityメニューの **Pasta → Build Playtest**。
- 前の試遊版は `output/Playtest/` に残してある。

## 遊び方

1. **列の手前を狙う。** スパゲッティの射程は約6m。吹き飛ばした敵はさらに奥へ飛び、ぶつかった敵も次の弾になる。地面の矢印が発射方向。
2. **右クリックで集める。** 近くの敵を、前方の緑色の輪へ2.6秒間誘導する。5秒で再使用できる。
3. **ダッシュで角度を作る。** 横へ回り込んで敵を重ねる。ダッシュ中は短時間無敵。1.15秒で再使用できる。
4. **折って連鎖させる。** 左クリックを長押しして金色で離すと、強く遠くへ発射。重い敵も一撃になる。敵同士の衝突なら弱い発射でも重い敵を倒せる。

6ラウンドすべて倒せばクリア。後半は三方向・四方向から敵が迫る。各ラウンド終了でHPが15回復し、次のラウンドまで4秒の回収時間がある。連鎖で倒すほど追加点が増える。

## 自動パスタとランダムドロップ

手動のパスタ折りに加え、拾った追加武器が自動で攻撃する。光るドロップの2.2m以内まで近づいて回収する。遠くのアイテムは自動回収されない。拾うと手元へ跳ね上がり、専用の音とGETカードで獲得を表示する。複数拾った場合も一つずつ表示し、新しい武器は表示から1.4秒後に動き始める。

最初の撃破と以降12体ごとの撃破では、未完成の武器からランダムでパスタが落ちる。同じパスタはLv.3まで強化される。

| 追加武器 | 効果 | レベルアップ |
| --- | --- | --- |
| フジッリ | らせんパスタが周囲を回り、近くの敵に命中 | 周回する本数が増える |
| ファルファッレ | 蝶形パスタが近くの敵を追尾 | 発射数が増え、間隔が短くなる |
| ラビオリ | 敵へ放物線で飛び、トマトソースを残す。範囲内の敵を減速し継続ダメージ | ソースの範囲・持続時間が増え、間隔が短くなる |

ほかの撃破は30%の確率で材料を落とす。4回連続で何も落ちなかった場合、次は必ず落ちる。未入手の材料は入手済みの4倍の重みで抽選されるが、重複もある。手動攻撃、自動パスタ、敵同士の衝突のどれで倒してもドロップ対象。非キルの命中や同じ敵への追撃では重複して落ちない。

## パスタコンボ

**マカロニ ＋ チーズ → ITALIAN MAC & CHEESE**

チーズソースが周期的にプレイヤーの周囲を攻撃する。材料は各1個で完成し、集めた順番は問わない。

**ITALIAN MAC & CHEESE ＋ ハム → BRITISH CARBONARA**

Gino D'Acampoのミームをモチーフにした進化。完成すると **F / ゲームパッドY** で大技を発射できる。丸眼鏡・お団子頭のおばあちゃんが車輪付きで登場し、0.85秒の予備動作から約6秒間、敵の群れを貫いて走る。最初の命中では消えず、倒した敵もドミノ連鎖を起こす。障害物に当たると向きを変え、走行を続ける。発射後のクールダウンは味付けLvに応じて18〜14秒。

ハムを先に拾っていても、マカロニとチーズが揃った時点で進化する。材料は消費せず、そのラン中ずっと有効。重複材料も味付けLv.3までの強化に使われる。武器・材料・進化はリトライ時にリセットされる。HUD左側に武器レベルとレシピの進行を表示する。

## 操作

| 操作 | キーボード / マウス | コントローラー |
| --- | --- | --- |
| 移動 / 視点 | WASD / マウス | 左 / 右スティック |
| 曲げて発射 | 左クリックまたはSpaceを長押し → 離す | RTまたはAを長押し → 離す |
| 挑発・集合 | 右クリック / E | LB |
| ダッシュ | 移動方向 + 左Shift（入力なしなら前方） | 左スティック + RB |
| パスタ切替 | Q、1 / 2 / 3 | X |
| British Carbonara（完成後） | F | Y |
| ポーズ | Esc | Start |
| リトライ | R / Space / クリック | A |

- **スパゲッティ：押し出す。** 短い前方扇状範囲の敵を、狙った方向へまとめて発射。
- **ペンネ：狙い撃ち。** 細く長い範囲で、より速く発射。遠くの列を狙う。
- **ラザニア：全周散らし。** 近くの敵を周囲へ放射状に飛ばす。包囲されたときに使う。

早く離しすぎるとパスタは残る。溜めすぎると弱く折れる。敵の「!」は攻撃予告で、発射か挑発で中断でき、ダッシュでも回避できる。

## 主な実装

- `DominoShot.cs`：1発全体で共有する連鎖記録、線分による衝突判定。
- `Enemy.cs`：飛行・衝突・連鎖発射、挑発への移動、重い敵のガード。
- `PastaHand.cs`：攻撃範囲、発射方向ガイド、挑発と集合場所の表示。
- `PlayerController.cs`：方向入力に沿うダッシュ、短時間無敵、再使用時間。
- `EnemySpawner.cs`：列・重い敵・四方向へ広がる6ラウンド構成。
- `KitchenInventory.cs` / `PastaKitchen.cs`：ランごとの武器成長、材料抽選、レシピ進化、自動攻撃。
- `KitchenPickup.cs` / `KitchenProjectile.cs` / `KitchenSauce.cs`：素材回収、追尾弾、自転車、ソースの命中処理。
- `KitchenVisuals.cs`：追加パスタ、素材、おばあちゃん自転車の実行時モデル。
- `GameManager.cs` / `Hud.cs`：勝利・敗北・再開と新ルールの日本語UI。

## 検証

**Pasta → Verify Blast Boundaries** でタイミング・攻撃範囲・連鎖の衝突境界を確認する。
**Pasta → Verify Kitchen Recipes** で全6通りの素材取得順、重複素材、進化条件、強化上限、抽選とリセットを確認する。ビルド時は両方を実行する。

Developmentビルドを以下で起動すると、仮想ゲームパッドによる統合テストを実行し、隣の `Verification/` に結果と実画面を保存する。通常起動ではテストは動かない。

```text
PastaLaVista.exe -pasta-smoke -screen-fullscreen 0 -screen-width 1280 -screen-height 720
```

検証対象は射程外への連鎖、重い敵への衝突、二重加点防止、挑発・ダッシュの入力とクールダウン、ポーズ中の飛行停止、6ラウンドの進行、勝利・敗北からのリトライ。この従来戦闘テストは自動武器を停止して手動操作を独立して確認する。

追加武器・コンボの統合テストは別の起動引数を使う。結果とスクリーンショットは `KitchenVerification/` に保存される。

```text
PastaLaVista.exe -pasta-kitchen-smoke -force-d3d11 -screen-fullscreen 0 -screen-width 1280 -screen-height 720
```

実際の落下・吸い寄せ・取得、非キルと重複ドロップ防止、3武器の命中、素材の取得順、マカロニチーズの範囲攻撃、おばあちゃん自転車の命中とクールダウン、ポーズと終了後の停止、リトライ時の片付けを検証する。
