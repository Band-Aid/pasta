# PASTA LA VISTA — パスタ・サバイバーズ

イタリア人の目の前でパスタを折って追い払う、3D版 Vampire Survivors 風ゲーム。Unity 6000.6.1f1 / URP。

## 試す

- 製品版：`output/SurvivorsRelease/PastaSurvivors.exe`（同じフォルダーのデータと一緒に起動）
- 開発版：`output/Survivors/PastaSurvivors.exe`（F1〜F6 のデバッグキー付き）
- Unityでは `Assets/Scenes/Survivors.unity` を開いて Play。シーンには起動用オブジェクトが1つあるだけで、ステージ・敵・UIはすべて実行時に生成される。
- 再ビルド：Unityメニューの **Pasta Survivors → Build Windows Release / Build Windows Playtest (Development)**。

## 遊び方

移動するだけで、持っているパスタ武器が自動で発動する。倒したイタリア人は「Mamma mia!」と叫んで逃げ出し、パスタの欠片（経験値）を落とす。

1. **レベルアップ**：欠片を集めると3〜4択から武器かパッシブを選ぶ。武器・パッシブとも最大6枠。
2. **主武器の切り替え**：持っている武器のうち1つが「主武器」。威力1.4倍・クールダウン25%短縮に加え、武器ごとの特性が付く。状況に応じて切り替える。
3. **進化**：武器をLv8にして対応パッシブを持った状態で宝箱を開けると進化する。宝箱はノンナ（エリート）とボスが落とす。
4. **ステージ**：10分生き延びるとボスが登場。倒すとクリアして次のステージが解放される。
5. **パワーアップ**：集めたコインでタイトルの「ノンナの食料庫」から永続強化を買える。
6. **視点**：見下ろし（標準）と一人称（FPS）を切り替えられる。一人称では主武器が照準の方向へ飛び、右下のレーダーで背後の敵を確認できる。

### ステージ

1. **ローマ** — トラステヴェレの広場。噴水、オベリスク、奥にコロッセオ。
2. **ヴェネツィア** — 運河に囲まれたサン・マルコ広場。ゴンドラ、鐘楼、大聖堂。

## 構成

コードは `Assets/Survivors/`（名前空間 `PastaSurvivors`）。旧プロトタイプのコードとは独立しており、パスタの折れるメッシュ（`PastaVisual`）と折れる音（`PastaAudio`）だけを流用している。

| 場所 | 内容 |
| --- | --- |
| `Scripts/Data/GameData.cs` | 武器・パッシブ・敵・ステージ（ウェーブ構成とイベント）・キャラ・ショップの数値。バランス調整はここ |
| `Scripts/Core/` | ゲーム進行（`SurvivorsGame`）、入力、セーブ、当たり判定用の簡易アリーナ、カメラ |
| `Scripts/Enemies/` | 敵のAI・空間グリッド（`EnemyManager`）、ウェーブ（`WaveDirector`） |
| `Scripts/Weapons/` | 8武器と弾・水たまり（`ShotSystem`） |
| `Scripts/Player/` | 移動・ダッシュ・ステータス・主武器・一人称、見た目とビューモデル |
| `Scripts/Visual/` | プリミティブを1メッシュに結合する `MeshKit`、イタリア人と小物のモデル、エフェクト |
| `Scripts/World/StageBuilder.cs` | 3ステージの街並みを生成 |
| `Scripts/UI/` | HUD、メニュー、ドット絵アイコン（コードで描画） |
| `Scripts/Audio/Audio.cs` | 効果音とタランテラBGMを実行時に合成 |
| `Editor/SurvivorsBuild.cs` | シーン生成とビルド |
| `Tests/` | 開発版専用の自動テストとバランス計測ボット |

## 検証

開発版を以下で起動すると自動テストが走り、`output/Survivors/Verification/` に結果とスクリーンショットを保存する。テスト用のセーブ枠を使うので、普段のセーブデータには影響しない。

```text
PastaSurvivors.exe -survivors-smoke -screen-fullscreen 0 -screen-width 1600 -screen-height 900
```

タイトル・キャラ/ステージ選択・ショップ、3ステージ、レベルアップ、主武器の切り替え、一人称、宝箱と全武器の進化、ボス撃破とステージ解放、ゲームオーバー、リトライ、ポーズを確認する。

バランス確認用に、無敵なしで1ステージを遊ぶボットもある（`[ステージ0〜2] [速度倍率] [キャラ0〜2] [ショップLv]`）。成長と被ダメージの内訳を `Verification/bot-stage*.txt` に記録する。

```text
PastaSurvivors.exe -survivors-bot 0 4 0 0
```

## 旧プロトタイプ：PASTA LA VISTA — DOMINO

パスタを折って敵を飛ばし、その敵を奥の敵にぶつける、一人称の連鎖アクション。Unity 6000.6.1f1 / URP。

### 試す

- Unityで `Assets/Scenes/Main.unity` を開いてPlay。シーンの再生成は不要。
- 新しい試遊版：`output/DominoPlaytest/PastaLaVista.exe`。同じフォルダーのデータと一緒に起動する。
- 再ビルド：Unityメニューの **Pasta → Build Playtest**。
- 前の試遊版は `output/Playtest/` に残してある。

### 遊び方

1. **列の手前を狙う。** スパゲッティの金色で折ったときの射程は約4m。吹き飛ばした敵はさらに奥へ飛び、ぶつかった敵も次の弾になる。地面の矢印が発射方向。
2. **右クリックで集める。** 近くの敵を、前方の緑色の輪へ2.6秒間誘導する。5秒で再使用できる。
3. **ダッシュで角度を作る。** 横へ回り込んで敵を重ねる。ダッシュ中は短時間無敵。1.15秒で再使用できる。
4. **折って連鎖させる。** 左クリックを長押しして金色で離すと、強く遠くへ発射。重い敵も一撃になる。敵同士の衝突なら弱い発射でも重い敵を倒せる。

3ラウンドすべて倒せばクリア。各ラウンド終了でHPが15回復する。連鎖で倒すほど追加点が増え、結果画面には最大連鎖人数と衝突で倒した人数が残る。

### 操作

| 操作 | キーボード / マウス | コントローラー |
| --- | --- | --- |
| 移動 / 視点 | WASD / マウス | 左 / 右スティック |
| 曲げて発射 | 左クリックまたはSpaceを長押し → 離す | RTまたはAを長押し → 離す |
| 挑発・集合 | 右クリック / E | LB |
| ダッシュ | 移動方向 + 左Shift（入力なしなら前方） | 左スティック + RB |
| パスタ切替 | Q、1 / 2 / 3 | X |
| ポーズ | Esc | Start |
| リトライ | R / Space / クリック | A |

- **スパゲッティ：押し出す。** 前方扇状範囲の敵を狙った方向へ発射。Tier 1/2/3 の近距離ヒット半径は 2.5/3.25/4m（連続 Perfect ボーナス前）。
- **ペンネ：狙い撃ち。** 細く長い範囲で速く発射。飛行距離は Tier 1/2/3 で 8/13/18m。
- **ラザニア：全周散らし。** 近くの敵を放射状に飛ばし、Tier 2 から重い敵のガードを破る。飛行距離は Tier 1/2/3 で 6/9/13m、再使用まで全 Tier で 2.5 秒。

敵を発射したあとの飛行距離はパスタと敵種によって変化する。敵の飛びやすさは Normal 1.0、Fast 1.4、Tough 0.4 倍。パスタのノックバックはスパゲッティ 1.0、ペンネ 0.9、ラザニア 1.3 倍。

### 発射バランス

| パスタ | Tier 1 / 2 / 3 の基本飛距離 | ノックバック倍率 | 飛行速度 | 特性 |
| --- | --- | --- | --- | --- |
| スパゲッティ | 7 / 11 / 15 m | 1.0 | 18 m/s | 基準 |
| ペンネ | 8 / 13 / 18 m | 0.9 | 24 m/s | 長距離連鎖 |
| ラザニア | 6 / 9 / 13 m | 1.3 | 18 m/s | Tier 2 から Tough の直接弾ガードを破る |

飛距離にはパスタのノックバック倍率と敵種の倍率（Normal 1.0 / Fast 1.4 / Tough 0.4）を掛ける。撃破時の吹き飛び速度とよろけ速度にも敵種の倍率を適用する。

早く離しすぎるとパスタは残る。溜めすぎると弱く折れる。敵の「!」は攻撃予告で、発射か挑発で中断でき、ダッシュでも回避できる。

### 主な実装

- `DominoShot.cs`：1発全体で共有する連鎖記録、線分による衝突判定。
- `Enemy.cs`：飛行・衝突・連鎖発射、挑発への移動、重い敵のガード。
- `PastaHand.cs`：攻撃範囲、発射方向ガイド、挑発と集合場所の表示。
- `PlayerController.cs`：方向入力に沿うダッシュ、短時間無敵、再使用時間。
- `EnemySpawner.cs`：列・重い敵・二方向からの3ラウンド構成。
- `GameManager.cs` / `Hud.cs`：勝利・敗北・再開と新ルールの日本語UI。

### 検証

**Pasta → Verify Blast Boundaries** でタイミング・攻撃範囲・連鎖の衝突境界を確認する。

Developmentビルドを以下で起動すると、仮想ゲームパッドによる統合テストを実行し、隣の `Verification/` に結果と実画面を保存する。通常起動ではテストは動かない。

```text
PastaLaVista.exe -pasta-smoke -screen-fullscreen 0 -screen-width 1280 -screen-height 720
```

検証対象は射程外への連鎖、パスタ別の射程と重い敵のガード、ラザニアの再使用時間、二重加点防止、挑発・ダッシュの入力とクールダウン、ポーズ中の飛行停止、3ラウンドの進行、勝利・敗北からのリトライ。
